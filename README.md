# Personal Portfolio

This is my personal portfolio website built with Next.js, React, Tailwind CSS, and TypeScript.

Live site: **piyushrajbanshi.com.np**

## About

I built this portfolio to introduce myself, show my projects, and keep track of the technologies I am learning and using.

The site focuses on a clean black-and-white design with small interactive details, including a physics-based interaction built with Matter.js.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Matter.js
* GitHub API

## Features

* Clean personal landing page
* About section
* Tech stack section
* GitHub activity section
* Projects section
* Contact/social links
* Theme toggle
* Physics interaction mode

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

Run linting:

```bash
npm run lint
```

## Project Structure

```txt
app/                  App routes, layout, metadata, and global styles
components/           Reusable UI and page sections
components/layout/    Layout components
components/sections/  Main portfolio sections
components/social/    Social link components
components/physics/   Physics interaction components
lib/                  Shared utilities
utils/                Helper functions
```
