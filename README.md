# Portfolio

A personal portfolio for Piyushee built with Next.js, React, Tailwind CSS, and a small Matter.js-powered physics interaction.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Project Structure

- `app/` - App Router entry points, global styles, and metadata.
- `components/sections/` - Main portfolio sections.
- `components/layout/` - Page-level layout pieces such as the bottom dock.
- `components/social/` - Shared social icon/link rendering.
- `components/data/` - Site configuration, navigation, skills, projects, and contact links.
- `components/physics/` and `components/fancy/physics/` - Physics mode UI and Matter.js integration.
- `lib/` and `utils/` - Shared helpers.

## Notes

This project uses Next.js 16. Check `node_modules/next/dist/docs/` before making framework-level changes.
